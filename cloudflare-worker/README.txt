MOLD FREE SCANNER V0.4 - CLOUDFLARE WORKER

1. Cloudflare Dashboard > Workers & Pages > Create > Worker.
2. Mở code editor của Worker, xóa code mẫu.
3. Copy toàn bộ nội dung worker.js vào và Deploy.
4. Mở URL workers.dev của bạn. Nếu thấy JSON có "ok":true là Worker chạy.
5. Trong app KhuanTEST V0.4: Tổng quan > "Cài Worker FREE" > dán URL workers.dev.
6. Bấm "Quét ngay".

Không cần OPENAI_API_KEY. Worker này không gọi OpenAI.
